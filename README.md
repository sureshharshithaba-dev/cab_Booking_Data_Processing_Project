# Cab Booking Data Processing Project

## 1. Project Description

This project is developed using Python.
It processes cab booking records, validates data,
calculates revenue, and generates summary reports.

## 2. Objectives

- Read cab booking data from CSV files.
- Validate customer booking records.
- Identify valid and invalid records.
- Calculate total cab revenue.
- Calculate average fare.
- Generate booking summary reports.
- Export processed records into CSV files.

## 3. Technologies Used

- Python 3.13
- Visual Studio Code
- CSV Module
- OS Module

## 6. How to Run the Project

Step 1: Install Python.

Step 2: Open the project folder in VS Code.

Step 3: Open the terminal.

Step 4: Run the command:

python main.py

Step 5: View the generated reports
inside the output folder.
